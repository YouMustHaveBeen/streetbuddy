# StreetBuddy — ТЗ и архитектура

Пометки в квадратных скобках показывают состояние кода: `[сделано]`, `[нет]`, `[частично: что не сделано]`, `[справочный]` (описание формы или шаг человека, кода нет).

## Цель

StreetBuddy — Telegram-бот, который превращает фото нарушения в заполненную форму [Traffic Watch](https://www.garda.ie/en/trafficwatchreport/); человеку остается поставить две галочки, пройти капчу и нажать «Submit Report».

1. [сделано] Бот доступен только участникам закрытой Telegram-группы: он проверяет членство пользователя в группе (для этого бот добавлен в группу администратором), а не участникам отвечает, что бот только для участников группы (текст: «This bot is only for members of the group.»; на нажатие кнопки не участником — всплывающее уведомление с тем же текстом). Интерфейс на английском, для пользователей iPhone и Android; работает в одном районе на северо-востоке Дублина (пункты 66–69).
2. [сделано] Бот работает только с нарушением «Parking Offences» (нелегальная парковка); остальные типы нарушений из формы не поддерживаются.
3. [сделано] Бот не отправляет форму сам и не обходит капчу: последний шаг всегда делает человек.
4. [сделано] Бот ни с кем не аффилирован; в названии и логотипе нет слов, указывающих на связь с госорганами.

## Форма Traffic Watch и откуда берутся данные

Форма — обычная страница Traffic Watch без фреймов (во фрейме только капча Google); все поля, кроме галочек и капчи, заполняет скрипт.

| Поле формы | id на странице | Откуда значение |
| --- | --- | --- |
| I confirm that this is not an emergency | NotAnEmergencyCheckbox | пользователь ставит сам |
| I confirm that I am willing to make a statement and attend Court | AttendCourtCheckbox | пользователь ставит сам |
| Click Here to Start | startBtn | пользователь нажимает сам; после этого появляются поля |
| Address or general location (текст) | Location | бот: адрес и GPS-координаты в виде `<адрес> (53.40123, -6.14567)`, 5 знаков |
| County (26 графств) | County | бот: из настроек района (Dublin) |
| Type of crime/incident (12 вариантов) | Crime | скрипт: всегда «Parking Offences» |
| Were you a (6 вариантов: Cyclist; Driver; E-Scooter User, E-Moped User, E-Cyclist; Motorcyclist; Passenger; Pedestrian) | RoadUserType | скрипт: сохранено на телефоне |
| Description | CrimeDescription | бот: шаблон по типу нарушения |
| Date (дд/мм/гггг) | crimeDate_1 | бот: дата отправки первого фото |
| First Name and Last Name (одно поле) | UserName | скрипт: сохранено на телефоне |
| Phone | Phone | скрипт: сохранено на телефоне |
| Email | Email | скрипт: сохранено на телефоне |
| Address | UserAddress | скрипт: сохранено на телефоне |
| How you wish to be contacted (Email / Phone Call / Text Message) | ContactMethod | скрипт: сохранено на телефоне |
| I'm not a robot | reCAPTCHA | пользователь |
| Submit Report | submitReport | пользователь |

[сделано] Скрипт заполняет все поля таблицы, кроме галочек, кнопок и капчи; значения для Location, County, Description и Date готовит бот.

5. [справочный] Фото и видео в форму загрузить нельзя; их передают в Traffic Watch позже, по запросу.
6. [сделано] Описание — до 300 символов: так указано в тексте формы; страница это не проверяет, бот держит лимит сам.
7. [справочный] Жалобу можно подать не позже 6 месяцев после нарушения; календарь даты раньше не пускает.
8. [сделано] Отдельного поля времени нет: время нарушения входит в описание.
9. [справочный] Форма не для экстренных случаев и обрабатывается не круглосуточно.
10. [справочный] Подтверждение с номером обращения приходит только на email.
11. [справочный] Сайт не использует часть ссылки после `#`; защита страницы запрещает только встраивание в чужие сайты и не мешает закладке и юзерскрипту.

## Пользовательский сценарий

Одна жалоба занимает около минуты: место, фото, два-три касания в боте, затем галочки, капча и кнопка на сайте Traffic Watch.

Один раз, при первом использовании:

12. [сделано] Команда /start показывает текст ниже (пока страниц политики приватности и инструкции нет, строки со ссылками не показываются):

```
StreetBuddy turns a photo of an illegally parked car into a pre-filled Garda Traffic Watch form. You tick the two boxes, pass the captcha and press Submit yourself.

This bot is not affiliated with An Garda Síochána.

A report may require you to give a statement in court.

To start a report, send your location.

Privacy policy: <link>
Installation guide: <link>

© OpenStreetMap contributors
```

/start посреди жалобы показывает этот текст и не трогает черновик.
13. [частично: закладки нет] Пользователь ставит скрипт: Android — закладка в Chrome или Firefox с Violentmonkey; iPhone — Safari с приложением «Userscripts» (оно работает только в Safari) или закладка в Safari.
14. [справочный] Пользователь настраивает Telegram так, чтобы ссылки открывались во внешнем браузере, или каждый раз выбирает «Open in browser».
15. [частично: закладки и страницы ее сборки нет] Пользователь вводит личные данные (имя, телефон, email, адрес, способ связи, «Were you a») один раз: юзерскрипт просит их при первом открытии формы и сохраняет в хранилище расширения; для закладки их вводят на странице инструкции, и страница прямо в браузере собирает закладку с этими данными внутри — на сервер ничего не уходит.

Каждая жалоба:

16. [сделано] Жалоба всегда начинается с места: пользователь присылает геолокацию (постоянная кнопка «Location» внизу чата или скрепка → «Location», там можно поставить точку на карте) или адрес текстом. Геолокацию умеет запрашивать только кнопка нижнего меню, поэтому «Location» — такая кнопка; остальные кнопки бота — инлайн. Фото, присланное до места, бот молча игнорирует и не запоминает.
17. [сделано] Как только бот пишет новое сообщение с кнопками, предыдущее сообщение с кнопками удаляется. «Cancel» есть на всех шагах, кроме итогового сообщения: бот останавливает жалобу, удаляет черновик и сообщение с кнопками, остальная переписка остается, и пишет «Report cancelled» без кнопок. Кнопки не остаются в середине разговора: на любое сообщение пользователя, которого бот на этом шаге не ждет (текст, геолокация, фото, файл), он отправляет текущий экран заново, а старый удаляет; исключение — момент выдачи ссылки, когда экран и так сразу исчезает. Новая геолокация или адрес посреди жалобы не начинают новую жалобу: для этого есть «Cancel». Нажатие старой кнопки только снимает «часики». При сбоях Nominatim из п.18 на сообщении тоже есть «Cancel».
18. [сделано] Бот проверяет, что место внутри района. Если нет или адрес не найден, бот отвечает «Sorry, this bot doesn't work in this area» и дальше не идет. При первом сбое Nominatim бот отвечает «Could not get the address. Please try again in a minute.» При втором сбое после геолокации — «Could not get the address. Please write it.»: координаты уже есть, район проверяется без Nominatim, текст сохраняется как есть. При сбое на адресе текстом координат нет, поэтому бот просит геолокацию: «Please send the location.»
19. [сделано] Бот показывает найденный адрес с кнопками «Confirm», «Edit», «Cancel». По «Edit» бот пишет «Write the correct address.»; введенный текст (до 100 символов, иначе «The address must be 100 characters or less.») сохраняется как есть, без нового запроса в Nominatim, координаты остаются прежними, и бот снова показывает адрес с теми же кнопками. Сообщение с адресом содержит только адрес. Фото до «Confirm» игнорируется, а сообщение с адресом удаляется и отправляется заново под фото.
20. [сделано] По «Confirm» бот пишет «Now send photos, the first one with the number plate.» Пользователь отправляет фото по одному или альбомом, лимита на их число нет. На каждое фото бот отвечает «Photo received. Send more photos or press Create report» с кнопками «Create report» и «Cancel»; на альбом отвечает один раз: Telegram не отмечает последнее фото альбома, поэтому бот ждет 2 секунды после очередного фото. Фото файлом (документом) бот не принимает; на него и на текст бот заново отправляет текущий экран (п.17). Номер машины распознается в фоне сразу после первого фото; остальные фото показывают расположение машины.
21. [сделано] По «Create report» бот показывает один экран с номером и временем: кнопки «Confirm», «Edit plate», «Change time», «Cancel». Если на первом фото несколько машин, сначала бот показывает все распознанные номера кнопками («Several plates found. Choose one.») и кнопку «Add» для ввода своего номера, и пользователь выбирает нужный. Если распознавание еще идет, бот дожидается его. Текст экрана — две строки: `Plate: 12-D-3456` и `Time: 02/11/2026 13:02`. Время по умолчанию — момент отправки первого фото. По «Edit plate» бот пишет «Write the plate number.»; номер до 15 символов, иначе «The plate number is too long. Please write it again.» По «Change time» бот пишет «Write the time as hh:mm.»; меняется только время, дата — всегда дата первого фото; неверное время и время позже текущего не принимаются: «Wrong time. Please write it again.»
22. [сделано] Пользователь выбирает один или несколько вариантов парковки кнопками-переключателями (касание ставит или снимает ✅) и нажимает «Done»; текст сообщения — «Choose one or more options, then press Done.» Нужен хотя бы один вариант, иначе всплывающее уведомление «Choose at least one option.» Кнопки: «on a cycle track», «on a footpath», «on a grass margin», «within 5m of a junction», «blocking a private driveway», «interfering with traffic flow», «obstructing and endangering traffic».
23. [сделано] Бот составляет описание по шаблону; отдельного экрана и правки описания нет, оно показывается в итоговом сообщении.
24. [сделано] Бот удаляет все свои промежуточные сообщения и сообщения пользователя, отправленные в ходе диалога (геолокация, адрес, исправления), кроме фото, и отправляет итоговое сообщение реплаем на последнее фото: строки `Plate:`, `Location:`, `Date and time:`, `Description:`, затем «Open the link in an external browser.» и кнопка-ссылка «Open form». В переписке остаются фото и итоговое сообщение под ними.
25. [справочный] Пользователь открывает ссылку в браузере, сам ставит две галочки и нажимает «Click Here to Start».
26. [частично: через закладку нет] Скрипт заполняет все поля (в Chrome — после касания закладки); пользователь проверяет данные, проходит капчу и нажимает «Submit Report».
27. [справочный] Гарда присылает email с номером обращения.

## Функциональные требования

Бот собирает данные о нарушении и упаковывает их в ссылку; скрипт распаковывает ссылку в поля формы.

Бот:

28. [сделано] Язык интерфейса — английский.
29. [сделано] Сначала проверяется место, потом распознается номер, чтобы фото из чужого района не тратили лимит; поэтому жалоба начинается с места.
30. [частично: проверки на реальных номерах не было] Номер распознает модель Workers AI, понимающая изображения, без лицензионного запрета для ЕС (кандидаты по порядку — Gemma 4 26B A4B, Gemma 3 12B, Mistral Small 3.1 24B); модель выбирается по проверке на реальных ирландских номерах; пока стоит Gemma 4 26B A4B (`@cf/google/gemma-4-26b-a4b-it`). Если распознать не удалось, бот пишет «Could not read the plate. Please write it.» Llama 3.2 Vision и Llama 4 Scout не используются: их лицензия не дает прав разработчику, живущему в ЕС.
31. [сделано] Одно и то же фото не распознается повторно: результат хранится по постоянному ID файла в Telegram.
32. [сделано] Если дневной лимит Workers AI исчерпан или распознать номер не удалось, бот просит ввести номер вручную.
33. [сделано] Адрес определяется через OpenStreetMap Nominatim — по геолокации или по адресу текстом; результаты кешируются (координаты для кеша округляются до 4 знаков, около 10 м); графство берется из настроек района. Вид адреса: дом, улица, район и eircode, например `12 Main Street, Clongriffin, D13 X1Y2`; если полного eircode в OSM нет — почтовый район из настроек: `12 Main Street, Clongriffin, D13`. Адрес текстом ищется только в прямоугольнике вокруг района (с запасом 50 м); если он не найден, бот отвечает так же, как на место вне района (п.18).
34. [сделано] Тип нарушения в форме всегда «Parking Offences»; кнопки бота — семь вариантов парковки из п.22.
35. [сделано] Шаблон описания на английском до 300 символов: номер машины, выбранные варианты парковки (через запятую, перед последним — «and»), место, дата и время. Если текст длиннее 300 символов, бот сокращает адрес в описании: убирает части с конца по запятой, а если этого мало, обрезает оставшуюся; полный адрес остается в поле Location. Дата — дд/мм/гггг, время — 24 часа, по Дублину. Пример: «Vehicle 12-D-3456 parked on a footpath and blocking a private driveway at \<address\> on 02/11/2026 at 13:02.»
36. [сделано] Ссылка имеет вид `https://www.garda.ie/en/trafficwatchreport/#sb=<данные>`, где данные — как можно более короткий JSON в base64url с ключами `l` (Location), `c` (County), `d` (Description), `t` (дата дд/мм/гггг).
37. [сделано] Бот хранит черновик текущей жалобы (file_id первого фото, ID сообщения с последним фото, ID сообщений бота и пользователя для последующего удаления, номер, место, варианты парковки, время) до выдачи ссылки.

Скрипт заполнения:

38. [частично: сборки закладки нет] Один код, две формы доставки: юзерскрипт (Violentmonkey, Userscripts) и закладка; в закладку весь код и личные данные пользователя вшиты целиком, без подгрузки внешнего файла.
39. [частично: закладки нет] Работает только на странице `garda.ie/en/trafficwatchreport`; юзерскрипт запускается как можно раньше после загрузки, закладка — когда пользователь ее коснется.
40. [сделано] Читает данные после `#sb=`, сразу убирает их из адресной строки (при закладке данные видны в адресной строке до касания закладки) и держит в sessionStorage до отправки формы, чтобы не потерять при перезагрузке.
41. [сделано] Ждет, пока пользователь поставит галочки и нажмет «Click Here to Start», затем заполняет поля по их id (таблица выше) так, чтобы проверки формы сработали как при ручном вводе; значения в списках ищет по видимому тексту варианта. Поля появляются не сразу: скрипт ждет их до 10 секунд после первого видимого поля; если кнопка «Click Here to Start» исчезла, а ни одно поле так и не появилось, те же 10 секунд отсчитываются от исчезновения кнопки. Перед заполнением проверяет данные из ссылки: структуру, допустимые значения, длину описания (300 символов), формат даты; вставляет их только как текст, без innerHTML.
42. [частично: закладки и страницы ее пересоздания нет] Личные данные и «Were you a» юзерскрипт хранит в хранилище расширения, где их можно изменить или удалить; в закладке они вшиты в ее код (скрипт берет их из `STREETBUDDY_PROFILE`, если она есть на странице) — чтобы изменить данные, закладку пересоздают на странице инструкции.
43. [сделано] Никогда не ставит подтверждающие галочки, не нажимает «Submit Report» и не трогает капчу.
44. [сделано] Если не найдено поле или вариант в списке, не заполняет ничего и сообщает: форма изменилась, заполните вручную. У скрипта есть номер версии.

Ежедневная проверка формы:

45. [нет] Каждый день в 6:00 по Дублину Worker загружает страницу формы и сверяет id полей и списки вариантов с эталоном. Поле даты crimeDate_1 создает скрипт сайта после «Click Here to Start», поэтому Worker дополнительно скачивает файл JavaScript сайта и проверяет, что в нем есть crimeDate_1.
46. [нет] Если что-то изменилось или страница не загрузилась, Worker присылает владельцу бота и в закрытую группу одно и то же сообщение в Telegram: «The Traffic Watch report form has changed, so the bot is temporarily not working. The developer has been notified.» — и перестает выдавать ссылки до повторного включения рубильником в админ-консоли (п.77). Пока бот выключен, на попытку получить ссылку пользователь получает то же сообщение.
47. [частично: обработчик расписания пустой, проверки нет] Расписание Cloudflare работает в UTC: запуски в 5:00 и 6:00 UTC, а проверка выполняется только в тот, когда в Дублине 6:00.

Инструкция по установке:

48. [нет] Страница с инструкциями для Android Chrome, Android Firefox и iPhone Safari, плюс как открывать ссылки из Telegram во внешнем браузере; на ней же прямо в браузере, без отправки на сервер, собирается закладка с личными данными; ее отдает тот же Worker.

## Архитектура

Бот — один Cloudflare Worker без базы личных данных; вся логика, не зависящая от мессенджера, вынесена в модуль core.

Личные данные не покидают телефон: бот готовит только ссылку.

```

│ чат с ботом      │─ фото, место►│ вебхук, диалог,      │
```

## Приватность и безопасность

Имя, телефон, email и адрес пользователя не попадают на сервер бота; место, фото и Telegram ID попадают и обрабатываются, как описано ниже.

Нужна полноценная политика приватности: кто оператор и как с ним связаться, какие данные обрабатываются (Telegram ID, фото, место, номер машины), основание обработки, сроки хранения, сторонние сервисы (Telegram, Cloudflare, OpenStreetMap), удаление данных по запросу. До публичного запуска — оценить, нужна ли DPIA.
59. [справочный] Номер машины и люди на фото — персональные данные по GDPR.
