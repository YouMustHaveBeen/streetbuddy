# StreetBuddy — архитектура

Пометки в квадратных скобках показывают состояние кода: `[сделано]`, `[нет]`, `[частично: что не сделано]`, `[справочный]` (описание формы или шаг человека, кода нет).

## Цель

StreetBuddy — Telegram-бот, который превращает фото нарушения в заполненную форму [Traffic Watch](https://www.garda.ie/en/trafficwatchreport/); человеку остается поставить две галочки, пройти капчу и нажать «Submit Report».

1. [сделано] Бот доступен только участникам закрытой Telegram-группы: он проверяет членство пользователя в группе (для этого бот добавлен в группу администратором), а не участникам отвечает, что бот только для участников группы (текст: «This bot is only for members of the group»; на выбор варианта «Were you a» не участником — всплывающее уведомление с тем же текстом и без ссылки, черновик остается; исключение — /admin, на который не администратор не получает никакого ответа, п.76). Интерфейс на английском, для пользователей iPhone и Android; работает в одном районе на северо-востоке Дублина (пункты 66–69).
2. [сделано] Бот работает только с нарушением «Parking Offences» (нелегальная парковка); остальные типы нарушений из формы не поддерживаются.
3. [сделано] Бот не отправляет форму сам и не обходит капчу: последний шаг всегда делает человек.
4. [сделано] Бот ни с кем не аффилирован; в названии и логотипе нет слов, указывающих на связь с госорганами.

## Форма Traffic Watch и откуда берутся данные

Форма — обычная страница Traffic Watch без фреймов (во фрейме только капча Google); все поля, кроме галочек и капчи, заполняет скрипт.

| Поле формы | id на странице | Откуда значение |
| --- | --- | --- |
| I confirm that this is not an emergency | NotAnEmergencyCheckbox | пользователь ставит сам |
| I confirm that I am willing to make a statement and attend Court | AttendCourtCheckbox | пользователь ставит сам |
| Click Here to Start | startBtn | пользователь нажимает сам; после этого появляются поля |
| Address or general location (текст) | Location | бот: адрес и GPS-координаты в виде `<адрес> (53.40123, -6.14567)`, 5 знаков |
| County (26 графств) | County | бот: из настроек района (Dublin) |
| Type of crime/incident (12 вариантов) | Crime | скрипт: всегда «Parking Offences» |
| Were you a (6 вариантов: Cyclist; Driver; E-Scooter User, E-Moped User, E-Cyclist; Motorcyclist; Passenger; Pedestrian) | RoadUserType | бот: пользователь выбирает кнопками (п.22) |
| Description | CrimeDescription | бот: шаблон по типу нарушения |
| Date (дд/мм/гггг) | crimeDate_1 | бот: дата отправки первого фото |
| First Name and Last Name (одно поле) | UserName | скрипт: сохранено на телефоне |
| Phone | Phone | скрипт: сохранено на телефоне |
| Email | Email | скрипт: сохранено на телефоне |
| Address | UserAddress | скрипт: сохранено на телефоне |
| How you wish to be contacted (Email / Phone Call / Text Message) | ContactMethod | скрипт: сохранено на телефоне |
| I'm not a robot | reCAPTCHA | пользователь |
| Submit Report | submitReport | пользователь |

[сделано] Скрипт заполняет все поля таблицы, кроме галочек, кнопок и капчи; значения для Location, County, Were you a, Description и Date готовит бот.

5. [справочный] Фото и видео в форму загрузить нельзя; их передают в Traffic Watch позже, по запросу.
6. [сделано] Описание — до 300 символов: так указано в тексте формы; страница это не проверяет, бот держит лимит сам.
7. [справочный] Жалобу можно подать не позже 6 месяцев после нарушения; календарь даты раньше не пускает.
8. [сделано] Отдельного поля времени нет: время нарушения входит в описание.
9. [справочный] Форма не для экстренных случаев и обрабатывается не круглосуточно.
10. [справочный] Подтверждение с номером обращения приходит только на email.
11. [справочный] Сайт не использует часть ссылки после `#`; защита страницы запрещает только встраивание в чужие сайты и не мешает закладке и юзерскрипту.

## Пользовательский сценарий

Одна жалоба занимает около минуты: место, фото, два-три касания в боте, затем галочки, капча и кнопка на сайте Traffic Watch.

Один раз, при первом использовании:

12. [частично: страницы политики приватности нет, вместо ссылки на нее стоит временная строка] Команда /start показывает текст ниже; слова «manual» и «Installation guide» в нем — ссылки на страницы руководства и установки (бот отправляет текст как HTML и отключает предпросмотр ссылок):

```
StreetBuddy turns a photo of an illegally parked car into a pre-filled Garda Traffic Watch report form. You tick the two boxes, pass the captcha and press Submit yourself.
Please note: a report may require you to give a statement in court.
***
First, read the manual.
Second, set up your phone: Installation guide.
Third, to start a report, send location to the bot.
***
This bot is not affiliated with An Garda Síochána.
(A link to the Privacy Policy will be here.)
© OpenStreetMap contributors
```

Строка про политику приватности временная: когда страница политики появится (п.58), ее заменит строка со ссылкой. /start посреди жалобы останавливает ее молча, как все команды меню (п.17); вместе с текстом бот посылает Telegram команду убрать из нижней панели кнопку «Location», которую показывали прежние версии бота.
13. [частично: варианта iPhone нет] Пользователь ставит скрипт: Android — закладка в Chrome; iPhone — Safari с приложением «Userscripts» (оно работает только в Safari) или закладка в Safari.
14. [справочный] Пользователь настраивает Telegram так, чтобы ссылки открывались во внешнем браузере, или каждый раз выбирает «Open in browser».
15. [сделано] Пользователь вводит личные данные (имя, телефон, email, адрес, способ связи) один раз: юзерскрипт просит их при первом открытии формы и сохраняет в хранилище расширения; для закладки их вводят на странице инструкции, и страница прямо в браузере собирает закладку с этими данными внутри — на сервер ничего не уходит.

Каждая жалоба:

16. [сделано] Жалоба всегда начинается с места: пользователь присылает геолокацию (скрепка → «Location», там можно поставить точку на карте) или адрес текстом. Постоянной кнопки «Location» внизу чата нет, все кнопки бота — инлайн. Новая геолокация на любом шаге начинает жалобу заново: старый черновик и экран с кнопками удаляются без «Report cancelled»; пока бот выключен (п.46), новая жалоба не начинается и старая остается как есть. Фото, присланное до места, бот молча игнорирует и не запоминает.
17. [сделано] Как только бот пишет новое сообщение с кнопками, предыдущее сообщение с кнопками удаляется. «Cancel» есть на всех шагах: бот останавливает жалобу, удаляет черновик и сообщение с кнопками, остальная переписка остается, и пишет «Report cancelled» без кнопок. На итоговом сообщении (п.24) «Cancel» и «Done» работают иначе, а команда /admin останавливает начатую жалобу молча (п.76). Кнопки не остаются в середине разговора: на любое сообщение пользователя, которого бот на этом шаге не ждет (текст, фото, файл), он отправляет текущий экран заново, а старый удаляет; исключение — момент выдачи ссылки, когда экран и так сразу исчезает. Адрес текстом на шаге, где текст не ждут, жалобу не начинает. Любая команда (/start и команды меню, п.84) останавливает жалобу молча, как /admin (п.76). Нажатие старой кнопки только снимает «часики». При сбоях Nominatim из п.18 на сообщении тоже есть «Cancel».
18. [сделано] Бот проверяет, что место внутри района. Если нет или адрес не найден, бот отвечает «Sorry, this bot doesn't work in this area» и дальше не идет. При первом сбое Nominatim бот отвечает «Could not get the address. Please try again in a minute» При втором сбое после геолокации — «Could not get the address. Please write it»: координаты уже есть, район проверяется без Nominatim, текст сохраняется как есть. При сбое на адресе текстом координат нет, поэтому бот просит геолокацию: «Please send the location»
19. [сделано] Бот показывает найденный адрес с кнопками «Confirm», «Edit», «Cancel». По «Edit» бот присылает прежний адрес, пустую строку и «Write the correct address»; введенный текст (до 100 символов, иначе «The address must be 100 characters or less») сохраняется как есть, без нового запроса в Nominatim, координаты остаются прежними, и бот снова показывает адрес с теми же кнопками. Сообщение с адресом содержит только адрес. Фото до «Confirm» игнорируется, а сообщение с адресом удаляется и отправляется заново под фото.
20. [сделано] По «Confirm» бот пишет «Now send photos, the first one with the number plate» Пользователь отправляет фото по одному или альбомом, лимита на их число нет. На каждое фото бот отвечает «Photo received. Send more photos or press Create report» с кнопками «Create report» и «Cancel» в одном ряду; на альбом отвечает один раз: Telegram не отмечает последнее фото альбома, поэтому бот ждет 2 секунды после очередного фото. Фото файлом (документом) бот не принимает; на него и на текст бот заново отправляет текущий экран (п.17). Номер машины распознается в фоне сразу после первого фото; остальные фото показывают расположение машины.
21. [сделано] По «Create report» бот показывает один экран с номером и временем: кнопки «Confirm», «Edit plate», «Change time», «Cancel». Если на первом фото несколько машин, сначала бот показывает все распознанные номера кнопками («Several plates found. Choose one») и кнопку «Add» для ввода своего номера (в одном ряду с «Cancel»), и пользователь выбирает нужный. Если распознавание еще идет, бот дожидается его. Текст экрана — две строки: `Plate: 12-D-3456` и `Time: 02/11/2026 13:02`. Время по умолчанию — момент отправки первого фото. По «Edit plate» бот присылает прежний номер, пустую строку и «Write the plate number»; номер до 15 символов, иначе «The plate number is too long. Please write it again». По «Change time» бот присылает прежнее время, пустую строку и «Write the time as hh:mm»; меняется только время, дата — всегда дата первого фото; неверное время и время позже текущего не принимаются: «Wrong time. Please write it again»
22. [сделано] Пользователь выбирает один или несколько вариантов парковки кнопками-переключателями (касание ставит или снимает ✅) и нажимает «Done»; текст сообщения — «Choose one or more options, then press Done». Нужен хотя бы один вариант, иначе всплывающее уведомление «Choose at least one option». «Done» и «Cancel» стоят в одном ряду под вариантами. Кнопки: «on a cycle track», «on a footpath», «on a grass margin», «within 5m of a junction», «blocking a private driveway», «interfering with traffic flow», «obstructing and endangering traffic». После «Done» бот спрашивает «Were you a:» (поле формы RoadUserType) кнопками с шестью вариантами формы в таком порядке: «Pedestrian», «Passenger», «Driver», «Cyclist», «Motorcyclist», «E-Scooter User, E-Moped User, E-Cyclist» — и «Cancel» отдельной строкой; касание варианта сразу ведет к итоговому сообщению (п.24). Выбранный вариант в итоговом сообщении не показывается, он только уходит в ссылку (п.36).
23. [сделано] Бот составляет описание по шаблону; отдельного экрана и правки описания нет, оно показывается в итоговом сообщении.
24. [сделано] Бот удаляет все свои промежуточные сообщения и сообщения пользователя, отправленные в ходе диалога (геолокация, адрес, исправления), кроме фото, и отправляет итоговое сообщение реплаем на последнее фото: описание нарушения (п.35), разбитое на строки: `Vehicle <номер>`, каждый выбранный вариант парковки на своей строке (`parked …`; при нескольких вариантах запятая в конце каждой строки, кроме последних двух, и «and» в начале последней), `at <адрес>`, `on <дата> at <время>.`; адрес тот же, что в описании, то есть при сокращении по п.35 он сокращен и здесь. Затем пустая строка, «Open the link in an external browser.» и кнопки: ряд с кнопкой-ссылкой «Open report» и под ним в одном ряду «Cancel» и «Done». В переписке остаются фото и итоговое сообщение под ними. «Cancel» удаляет только это сообщение вместе с кнопками, фото остаются, и строку этой жалобы в журнале (п.89): жалоба не считается. «Done» убирает все кнопки, включая «Open report», а последнюю строку заменяет на `Report sent 03/11/2026 10:35`: дата и время нажатия «Done», по Дублину. Строка журнала жалоб (п.89) пишется при выдаче ссылки, и «Done» ее не меняет. Для этого текст отчета без последней строки хранится в D1 (с ID чата и сообщения, а также ID строки журнала) до нажатия «Done» или «Cancel», но не дольше 48 часов; если текста уже нет, «Done» только убирает кнопки, а «Cancel» удаляет сообщение. Кнопки итогового сообщения не затрагивают новую жалобу, начатую после него.
25. [справочный] Пользователь открывает ссылку в браузере, сам ставит две галочки и нажимает «Click Here to Start».
26. [сделано] Скрипт заполняет все поля (в Chrome — после касания закладки); пользователь проверяет данные, проходит капчу и нажимает «Submit Report».
27. [справочный] Traffic Watch присылает email с номером обращения.

## Функциональные требования

Бот собирает данные о нарушении и упаковывает их в ссылку; скрипт распаковывает ссылку в поля формы.

Бот:

28. [сделано] Язык интерфейса — английский. Сообщения бота из одного предложения не заканчиваются точкой, у сообщений из нескольких предложений точки нет только в конце; описание нарушения (п.35) и последняя строка итогового сообщения (п.24) с точкой.
29. [сделано] Сначала проверяется место, потом распознается номер, чтобы фото из чужого района не тратили лимит; поэтому жалоба начинается с места.
30. [частично: проверено на одном фото, номер распознан верно; серии реальных ирландских номеров не было] Номер распознает модель Workers AI, понимающая изображения, без лицензионного запрета для ЕС (кандидаты по порядку — Gemma 4 26B A4B, Gemma 3 12B, Mistral Small 3.1 24B); модель выбирается по проверке на реальных ирландских номерах; пока стоит Gemma 4 26B A4B (`@cf/google/gemma-4-26b-a4b-it`). Если распознать не удалось, бот пишет «Could not read the plate. Please write it.» Llama 3.2 Vision и Llama 4 Scout не используются: их лицензия не дает прав разработчику, живущему в ЕС.
31. [сделано] Одно и то же фото не распознается повторно: результат хранится по постоянному ID файла в Telegram.
32. [сделано] Если дневной лимит Workers AI исчерпан или распознать номер не удалось, бот просит ввести номер вручную.
33. [сделано] Адрес определяется через OpenStreetMap Nominatim — по геолокации или по адресу текстом; результаты кешируются (координаты для кеша округляются до 4 знаков, около 10 м); графство берется из настроек района. Вид адреса: дом, улица, район и eircode, например `12 Main Street, Clongriffin, D13 X1Y2`; если полного eircode в OSM нет — почтовый район из настроек: `12 Main Street, Clongriffin, D13`. Адрес текстом ищется только в прямоугольнике вокруг района (с запасом 50 м); если он не найден, бот отвечает так же, как на место вне района (п.18).
34. [сделано] Тип нарушения в форме всегда «Parking Offences»; кнопки бота — семь вариантов парковки из п.22.
35. [сделано] Шаблон описания на английском до 300 символов: номер машины, выбранные варианты парковки (через запятую, перед последним — «and»), место, дата и время. Если текст длиннее 300 символов, бот сокращает адрес в описании: убирает части с конца по запятой, а если этого мало, обрезает оставшуюся; полный адрес остается в поле Location. Дата — дд/мм/гггг, время — 24 часа, по Дублину. Пример: «Vehicle 12-D-3456 parked on a footpath and blocking a private driveway at \<address\> on 02/11/2026 at 13:02.»
36. [сделано] Ссылка имеет вид `https://www.garda.ie/en/trafficwatchreport/#sb=<данные>`, где данные — как можно более короткий JSON в base64url с ключами `l` (Location), `c` (County), `d` (Description), `t` (дата дд/мм/гггг), `r` (Were you a).
37. [сделано] Бот хранит черновик текущей жалобы (file_id первого фото, ID сообщения с последним фото, ID сообщений бота и пользователя для последующего удаления, номер, место, варианты парковки, время) до выдачи ссылки. У каждого черновика свой случайный ID, и все изменения и удаления черновика идут по нему: отложенные действия отмененной или замененной жалобы (поиск адреса, ожидание распознавания, смена экрана, выдача ссылки) не задевают новый черновик.

Скрипт заполнения:

38. [сделано] Один код, две формы доставки: юзерскрипт (приложение «Userscripts» на iPhone) и закладка; в закладку вшиты личные данные пользователя и команда загрузить скрипт с Worker (`/streetbuddy.user.js`): так закладка остается короткой, около 500 символов, а при обновлении скрипта ее пересоздавать не нужно.
39. [сделано] Работает только на странице `garda.ie/en/trafficwatchreport`; юзерскрипт запускается как можно раньше после загрузки, закладка — когда пользователь ее коснется.
40. [сделано] Читает данные после `#sb=`, сразу убирает их из адресной строки (при закладке данные видны в адресной строке до касания закладки) и держит в sessionStorage до отправки формы, чтобы не потерять при перезагрузке.
41. [сделано] Ждет, пока пользователь поставит галочки и нажмет «Click Here to Start», затем заполняет поля по их id (таблица выше) так, чтобы проверки формы сработали как при ручном вводе; значения в списках ищет по видимому тексту варианта. Поля появляются не сразу: скрипт ждет их до 10 секунд после первого видимого поля; если кнопка «Click Here to Start» исчезла, а ни одно поле так и не появилось, те же 10 секунд отсчитываются от исчезновения кнопки. ## Архитектура

Бот — один Cloudflare Worker без базы личных данных; вся логика, не зависящая от мессенджера, вынесена в модуль core.

Личные данные не покидают телефон: бот готовит только ссылку.

Имя, телефон, email и адрес пользователя не попадают на сервер бота; место, фото и Telegram ID попадают и обрабатываются, как описано ниже.

## Команды меню

84. [сделано] Список команд под кнопкой «Menu» у поля ввода задается скриптом `scripts/set-commands.sh` (метод Telegram `setMyCommands` для всех личных чатов; токен бота скрипт берет из переменной окружения при запуске, в репозитории токена нет): `/manual` — «User manual», `/setup` — «Set up guide», `/hotspots` — «Hotspots», `/reportmap` — «Report map», `/feedback` — «Feedback». `/start` и `/admin` в списке нет. Любая команда, в том числе `/start`, останавливает начатую жалобу молча (п.17).
85. [сделано] `/manual` присылает сообщение, в котором только ссылка «User manual» на страницу руководства (п.83); `/setup` — только ссылка «Set up guide» на страницу установки (п.48).
86. [сделано] `/hotspots` присылает «Hotspots» и под ним строки вида `1. 12 Main Street, Clongriffin, D13 (5)`: адрес и в скобках число разных номеров, от большего к меньшему, не больше пяти; показываются только места, где жалоб на не меньше 10 разных номеров (чтобы одна машина, на которую жалуются снова и снова, не делала место видимым); пока таких мест нет — «No hotspots yet». Места журнала (п.89) в пределах 50 м друг от друга, как в п.63, считаются одним, в том числе цепочкой (A рядом с B, B рядом с C); в строке стоит адрес, который в такой группе встречается чаще всего, при равенстве — адрес последней жалобы. Номера машин не показываются. Топ-5 считается каждую ночь по всему журналу (п.61, 2 месяца) и хранится в D1 до следующей ночи.
87. [частично: заглушка вместо карты] `/reportmap` присылает «Report map» с четырьмя кнопками, по две в ряду: «Today», «Week», «Last month», «Month before»; на любую бот пока отвечает сообщением «The map will be here». Карта будет страницей Worker с отметками мест и дат жалоб, без номеров машин. Периоды: Today — сегодня; Week — семь дней до вчера включительно (сегодня среда — с прошлой среды по этот вторник); Last month — от сегодняшнего числа прошлого месяца до вчера (сегодня 15 мая — с 15 апреля по 14 мая); Month before — тот же отрезок месяцем раньше (с 15 марта по 14 апреля).
88. [частично: сохранение сделано, показа в /admin нет] `/feedback`: бот пишет «Write your feedback» с кнопкой «Cancel» (она убирает экран без сообщения), пользователь присылает текст до 1000 символов (иначе «The feedback must not be longer than 1000 characters»), бот сохраняет его в D1 вместе с Telegram ID автора на 2 месяца (п.61) и отвечает «Thank you for your feedback». Читать обратную связь будут администраторы кнопкой «Feedback» экрана /admin (п.80).
89. [сделано] Когда бот выдает ссылку (п.24), в журнал жалоб в D1 пишется строка: номер, варианты парковки, адрес, координаты, время и дата по Дублину (колонка `day`, `гггг-мм-дд`); без Telegram ID. Если потом под итоговым сообщением нажата «Cancel», строка удаляется. Если «Cancel» нажата позже чем через 48 часов (текст итогового сообщения уже стерт, п.61) или после ночного подсчета, строка и число за прошедший день остаются. Каждую ночь в запуске, когда в Дублине 3:00 (п.47), бот считает статистику за вчерашний день по времени Дублина (сколько выдано ссылок и сколько раз выбран каждый из семи вариантов парковки; строка на день, без срока хранения), выбирая строки журнала по `day`, и топ-5 мест для /hotspots (п.86). Строка, записанная между применением миграции и деплоем, имеет пустой `day`: ее день определяется по времени записи (`docs/decisions.md`). Повторный подсчет дает те же строки.
