# Адреса с компьютера: инструкция

Как посмотреть справочник адресов на карте, добавить точки и линии и поправить уже внесенное. Работа идет на MacBook, в терминале и на сайте geojson.io. Бот и база меняются только в конце, обычным путем: PR, загрузка файла, одобрение в `/admin`.

## Что получится

1. Файл `exports/directory.geojson` со всем справочником (в том числе адреса из OSM), его открывают на geojson.io.
2. Новые и исправленные адреса сохраняются в `config/walks/walk-N.geojson`.
3. Этот файл идет в репозиторий через ветку и PR и загружается во входящие, дальше как после обычного обхода (`docs/architecture.md`, п.98).

## Шаг 1. Выгрузить справочник

1. Открой Terminal и вставь:

```
cd ~/YouMustHaveBeen/StreetBuddy
git checkout main
git pull
node scripts/export-directory.mjs
```

2. Должна появиться строка вида `700 addresses written to exports/directory.geojson`. Папка `exports` не попадает в репозиторий (там данные OSM).
3. Если wrangler пишет `7403 "account is not valid or is not authorized"`: `npx wrangler logout`, затем отдельной командой `npx wrangler login`, затем повтори.

## Шаг 2. Открыть выгрузку на карте

1. Открой в браузере сайт geojson.io. Откроется пустая карта. Вверху над картой ряд кнопок: стрелка, точка, линия, многоугольник, квадрат, круг, справа «Import» и «Export». Под картой три вкладки: «JSON», «Table», «List».
2. Нажми «Import». Откроется окно выбора файла. Выбери `exports/directory.geojson` в папке `StreetBuddy` (папка `YouMustHaveBeen` в домашней папке). Если окно не открылось, перетащи этот файл из Finder прямо на карту.
3. Карта приблизится к району, адреса появятся на ней точками, линиями и закрашенными областями. Приблизь карту колесиком мыши или двумя пальцами на трекпаде.
4. Нажми на любую точку на карте. Она станет выбранной, над картой появится надпись «1 feature selected» («выбран 1 объект»). Это значит «выбрать объект». Одновременно внизу откроется «Feature Editor» с таблицей «Properties» (свойства): слева в колонке «Name» названия полей, справа в «Value» их значения. Там будут `address` (текст адреса), `kind` (вид) и `source` (откуда адрес: `osm`, `walk` или `user`).
5. Чтобы убрать выбор, нажми на пустое место карты. Если нажатия по карте ничего не выбирают, проверь, что слева в ряду кнопок подсвечена стрелка. Если нет, нажми на нее.

## Шаг 3. Добавить адрес

1. Точка (дом, магазин, остановка): нажми кнопку с точкой над картой, затем один раз нажми на карте туда, где адрес.
2. Линия (длинный дом, улица без номера): нажми кнопку с ломаной линией, нажимай по карте в каждой точке изгиба, последний раз нажми дважды. Линия идет вдоль фасада со стороны, где стоят машины.
3. Территория: нажми кнопку с многоугольником, нажимай по карте по углам, последний раз нажми дважды. Внутри территории домов быть не должно.
4. После постановки нажми кнопку со стрелкой, затем на только что поставленный объект. Внизу в «Feature Editor», в таблице «Properties», есть строка «New key» / «New value». Нажми на «New key», введи `address`, нажми на «New value», введи текст адреса, нажми кнопку «+» справа в строке. Появится строка с твоим адресом. Тем же способом добавь вторую строку: `kind` и значение вида.
5. Что писать:
   1. `address`: номер дома первым (`34 Parkside Crescent`), `St` вместо Street, перекресток как `A & B`, до 100 символов, без почтового района.
   2. Адрес без номера дома: сначала объект, потом комплекс, в конце улица (`Block 9 New Priory, Main St`, `Bus stop, Block 1b, Parkside, Main St`). Слово `Block` пишется полностью.
   3. `kind`: одно слово из списка `house`, `appt`, `facility`, `spot`, `area`. Для территории только `area`, и `area` только у территории.
6. Поле `source` для нового адреса заполнять не нужно.

## Шаг 4. Исправить существующий адрес

1. Сдвинуть точку: нажми кнопку со стрелкой, затем нажми на точку, чтобы выбрать ее, и перетащи ее мышью на новое место (зажми кнопку, двигай, отпусти). Поля `address` и `kind` в таблице остаются как есть, их менять не надо: текст должен остаться тем же, чтобы бот понял, что это тот же адрес.
2. Исправить линию или территорию: нажми кнопку со стрелкой, затем нажми на линию или территорию, чтобы выбрать ее. На ней появятся маленькие кружки на изгибах (вершины). Перетащи нужный кружок на новое место. Если кружков не видно, нажми на линию еще раз. Чтобы добавить новую вершину, нажми дважды на линию в нужном месте.
3. Изменить вид: выбери объект (шаг 2, пункт 4), в таблице «Properties» нажми на значение рядом с `kind`, сотри его, введи новый вид и нажми Enter. Вид территории менять нельзя.
4. Менять текст адреса в файле не нужно. Бот увидит новый текст как другой адрес. Текст правится в `/admin`, кнопка «Edit text».
5. Удалить адрес с карты в файле нельзя: он останется в справочнике. Удаляй командой `node scripts/delete-address.mjs "текст адреса"` (или в `/admin`, кнопка «Delete»).

## Шаг 5. Сохранить файл

1. Нажми «Export» справа над картой и выбери формат GeoJSON (в меню пункт «GeoJSON»). Файл скачается в папку Downloads, обычно с именем `map.geojson`. Если сайт сохраняет под другим именем, смотри имя в списке загрузок браузера.
2. Сразу перетащи файл в Finder из Downloads в папку `YouMustHaveBeen`: Terminal не может читать Downloads (ошибка `EPERM`), а эту папку читает.

## Шаг 6. Оставить только новое и исправленное

1. В Terminal вставь (имя файла замени на свое, если оно другое):

```
cd ~/YouMustHaveBeen/StreetBuddy
node scripts/diff-directory.mjs ~/YouMustHaveBeen/map.geojson
```

2. Скрипт сравнивает сохраненный файл с `exports/directory.geojson`. Все, что совпадает, он выбрасывает. Остальное пишет в следующий по номеру `config/walks/walk-N.geojson` и сообщает, сколько адресов записано.
3. Если пишет `Nothing new`, значит ты ничего не изменила, файл не создан.
4. Если пишет, что у адресов нет `address` или `kind`, открой файл `config/walks/walk-N.geojson` на geojson.io, заполни поля и сохрани (Save, GeoJSON). Скачанный файл скопируй из Downloads поверх `config/walks/walk-N.geojson` (в Finder: перетащи с зажатой клавишей Option, согласись на замену).

## Шаг 7. Отправить в репозиторий и загрузить

1. Файл обхода идет в репозиторий через ветку и PR, как обычный обход. Скажи Claude: «положи walk-N в PR» (с номером из шага 6).
2. После merge вставь в Terminal:

```
cd ~/YouMustHaveBeen/StreetBuddy
git checkout main
git pull
node scripts/load-walk.mjs config/walks/walk-N.geojson
```

3. Открой бота, команда `/admin`, кнопка «Incoming addresses». Новые адреса одобряй по одному или кнопкой «Approve all from the walk».
4. Исправленный адрес с тем же текстом, что в справочнике, появится экраном-группой дублей с кнопками «Keep old» и «Keep new1» (если адресов несколько — «Keep old1», «Keep old2», «Keep new2» и т.д., подписи на карте те же). Если неверны все новые адреса, нажми «Reject all»: они отклонятся, старый останется. Если старых адресов несколько, «Keep» любого из них удаляет остальные старые адреса из справочника. «Keep new1» заменяет старый адрес новым, его номер сохраняется; «Keep old» оставляет старый.

## Чего скрипты не делают

1. Не меняют базу: `export-directory.mjs` только читает, `diff-directory.mjs` работает с файлами на твоем компьютере.
2. Не удаляют адреса из справочника. Удалить адрес можно командой `node scripts/delete-address.mjs "текст адреса"` из папки StreetBuddy: она покажет адрес и спросит y/n.
3. Не берут адреса из OSM: исправленный адрес с `source` равным `osm` скрипт пропускает и пишет, сколько пропустил (данные OSM в публичный репозиторий не идут). Такие адреса правятся в `/admin`.
4. Не работают с неоднозначным текстом. Скрипт отказывает на весь файл (не создает ничего) и называет адреса, если текст исправленного или нового адреса встречается в справочнике несколько раз или в самом файле у двух новых и исправленных объектов (в том числе у двух частей одной улицы): он не может понять, какой из них имеется в виду. Что делать: в `/admin` («Edit directory»: найди адрес в списке или поиском по тексту) сделай текст уникальным кнопкой «Edit text» или удали лишний адрес кнопкой «Delete». Кнопка «Move» есть только у точки; линия и территория перемещаются только через файл обхода. После правки в `/admin` повтори шаг 1 (новая выгрузка), открой новую выгрузку на geojson.io, внеси правки и повтори шаги 5 и 6.
5. Не переименовывают адреса: смена текста в файле создает новый адрес.
